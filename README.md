# Kul Backtests

*guilty until backtested.*

The code, pre-registrations and raw results behind every Kul Backtests video. A Danish futures trader and a black cat named Kul test the trading strategies the internet swears by: exactly as claimed, on real futures data, against coin flips and prop-firm rules.

| Episode | Video | Folder |
|---|---|---|
| 1 | Using an Instagram Reel to Pass a Prop Firm | [`ep01-ema9-vwap-claim/`](ep01-ema9-vwap-claim/) |

Each folder has:
- the pre-registration (the rules and pass bar, written before the test ran);
- the code (TradingView Pine);
- the results;
- a README.

Raw market data is not included (it's licensed).

Found a bug? Open an issue. Want a strategy tested? Comment on the video.

**Not financial advice.** Backtests and simulations are hypothetical, not live trading results. Futures can lose more than you invest.
