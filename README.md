# Kul Backtests

*guilty until backtested.*

The code, pre-registrations and raw results behind every Kul Backtests video. A Danish futures trader and a cartoon cat named Kul test the trading strategies the internet swears by: exactly as claimed, on real futures data, against coin flips and prop-firm rules.

| Episode | Video | Folder |
|---|---|---|
| 1 | Using an Instagram Reel to Pass a Prop Firm | [`ep01-ema9-vwap-claim/`](ep01-ema9-vwap-claim/) |
| 2 | I Let My Cat Trade a Prop Firm Account | [`ep02-cat-vs-bots/`](ep02-cat-vs-bots/) (data only) |

Episode 1's folder has:
- the pre-registration (the rules and pass bar, written before the test ran);
- the code (TradingView Pine);
- the results;
- a README.

Episode 2's folder is data only: the bot list with every author or paper, all 146,000 cat runs and the results. It holds no code: each bot's Pine script stays on TradingView with its author, and the prop simulator is not published.

Raw market data is not included (it's licensed).

Found a bug? Open an issue. Want a strategy tested? Comment on the video.

**Not financial advice.** Backtests and simulations are hypothetical, not live trading results. Futures can lose more than you invest.
